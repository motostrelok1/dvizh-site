## Главное правило

Исследование является источником истины. Содержимое и дизайн начального приложения — **оригинальный самостоятельный прототип**, а не проверенная копия оригинала. Не подменять оригинальные фотографии/логотипы автоматически. Использовать лицензированные ассеты. Не отправлять тестовые заявки в чужую CRM.

## Квиз: исходные наблюдения

Шаги публичного HTML: теория (онлайн / класс / совмещённо); трансмиссия (механика / автомат / дополнительное вождение); опыт; форма оплаты (полностью / рассрочка / материнский капитал); желаемая дата начала. Затем имя + телефон. Перед реализацией условий перехода и итоговых экранов требуется активная проверка в браузере. Сейчас реализованы контролируемые ответы, назад, простой прогресс и демонстрационное завершение без отправки.

## Критерии приёмки

- Все секции, сценарии и маршруты покрыты таблицей исследований.
- На 1440, 1024, 768 и 390 px собраны эталонные снимки и снимки реализации.
- Все основные сценарии без ошибок JS и без горизонтальной прокрутки.
- Каждое отличие визуального эталона зарегистрировано и устранено или обосновано.
- Клиент не содержит секретов, формы не пишут в сторонний сервис.
- Только с разрешёнными текстами, фотографиями, фирменными знаками.
