## Ближайшая последовательность

1. Запустить `npm install && npx playwright install chromium && npm run research:inventory` на машине с доступом к сайту.
2. Сохранить эталонные скриншоты, токены дизайна и проверенные маршруты; описать все расхождения.
3. Провести REA/CDP наблюдения по интерактивным сценариям, без отправки заявок.
4. Заменить демо-секции на точные секции по снимкам.
5. Выполнить `npm run check && npm test && npm run build && npm run test:e2e` и зафиксировать результаты.

**Никаких заявлений о готовом клоне, прошедших проверках или запущенном REA до фактического выполнения.**
