# План тестирования

| Группа | Проверка |
| --- | --- |
| Static | TypeScript check, Vite build |
| Unit | Количество шагов, уникальные ID, валидация ответа |
| E2E | Меню, квиз, переходы, возврат, демо-форма |
| Visual | Снимки эталона vs реализация для 4 viewport |
| Responsive | Нет горизонтального скролла; шапка и CTA доступны |
| Accessibility | Tab, Escape, focus return, aria состояния, контраст |
| Security | Без секретов, чужих endpoint, сетевых POST |
| Performance | Размер JS, LCP, CLS, оптимизация изображений |

Результаты запусков заносить в PROGRESS. На стартовом этапе автоматические тесты **созданы, но ещё не выполнены**.
