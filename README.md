# dvizh-site

Независимая реализация сайта автошколы, вдохновлённая исследованием публичного лендинга «Феликс Плюс» (Вологда). **На текущем этапе это работающий по коду концепт, не точная копия и не официальный сайт оригинальной автошколы.** Ссылки и заявки оригинала не используются.

## Быстрый старт

Требуется Node.js 22+.

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run check
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Снять инвентарь публичной страницы (только чтение):

```bash
npm run research:inventory
```

## Безопасность и права

Не публиковать тексты, логотипы, фотографии и другие чужие защищённые материалы без разрешения. На первом этапе формы не отправляют реальные данные и не подключены к CRM. Перед запуском заявок потребуется официальная политика конфиденциальности и согласованный backend. Отдельный домен и маркировка исключают путаницу с оригиналом.
